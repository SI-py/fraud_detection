# Скоринг транзакций

Запустите Docker Desktop, откройте терминал в папке проекта и выполните:

```bash
docker compose up -d --build
```

Дождитесь запуска контейнеров и откройте:

- [Приложение](http://localhost:8501) — загрузка CSV и результаты скоринга.
- [Kafka UI](http://localhost:8080) — просмотр топиков и сообщений.

Дальше в интерфейсе всё понятно.

Для остановки проекта:

```bash
docker compose down
```

Для остановки с удалением всех данных PostgreSQL и сообщений Kafka:

```bash
docker compose down -v
```
